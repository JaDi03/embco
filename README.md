# Embco

Plataforma de microtareas (etiquetado de datos) con pagos instantáneos en USDC sobre Arc Testnet.

## Estructura

| Carpeta     | Contenido                                   |
|-------------|---------------------------------------------|
| `frontend/` | App Next.js (UI + API routes)               |
| `contracts/`| Contratos Solidity (Hardhat) — pendiente    |

## Desarrollo

```bash
cd frontend
cp .env.example .env.local   # rellenar valores
npm install
npm run dev
```
